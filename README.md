# Casino — рулетка

Европейская рулетка (числа 0–36) на C++/CLI и Windows Forms.

## Как собрать

1. Установить Visual Studio 2022 с компонентами **«Разработка классических приложений на C++»** и **«Поддержка C++/CLI»**.
2. Открыть `casino test 2.sln`.
3. Собрать и запустить (F5).

Гифки `win.gif`, `lose.gif`, `no_money.gif` при сборке копируются рядом с exe.
Если их нет, игра работает, просто без анимации.

## Как играть

- Выбери, на что ставишь: число, ряд (`row1`–`row3`), дюжину, половину, чёт/нечет или цвет.
- Введи ставку или поменяй её кнопками `+10`, `-10`, `half`, `all in` и т. д.
- Нажми **Spin**.

| Ставка | Выплата |
|---|---|
| Одно число | 35 : 1 |
| Ряд, дюжина (`1-12`, `13-24`, `25-36`) | 2 : 1 |
| `1-18`, `19-36`, `EVEN`, `ODD`, `red`, `black` | 1 : 1 |

На зеро все ставки, кроме ставки на сам 0, проигрывают. Стартовый баланс — 100.
